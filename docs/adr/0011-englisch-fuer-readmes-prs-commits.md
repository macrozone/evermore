# 0011 – Englisch für READMEs, Pull Requests, Commits und Code-Kommentare

- Status: accepted
- Datum: 2026-10-03
- Entscheider: maw

## Kontext und Problem

Bisher galt: Code und UI-Texte englisch, Beads und Doku deutsch. READMEs und PRs sind aber oft die erste Anlaufstelle für Menschen und Agents ausserhalb des Projekts (und in maw-city gilt bereits Englisch).

## Entscheidung

- **Englisch:** alle `README.md`, Pull Requests (Titel und Beschreibung), Commit-Messages, Code-Kommentare, Code und UI-Texte.
- **Deutsch bleibt:** Beads, `docs/vision.md`, ADRs und Planungsartefakte.

## Konsequenzen

- Bestehende deutsche READMEs werden übersetzt (u.a. Art Bible `docs/art/README.md`, Moodboard-READMEs, Package-READMEs).
- `AGENTS.md` und `bd remember konventionen` werden angepasst.
